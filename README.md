# windowsdesktoptool

A Windows desktop session manager that saves and restores your desktop state — open applications, window positions, and sizes — so you can close everything and bring it all back with a single click.

## Features (Planned)

- Save snapshots of your current desktop state (open apps, window positions, sizes)
- Restore saved sessions, relaunching apps and repositioning windows
- Multiple named sessions/profiles
- System tray integration for quick access

## Building

```
cargo build --release
```
